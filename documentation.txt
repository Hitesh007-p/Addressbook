1. Project Overview :->

This project is a console-based Address Book Management System developed in C language.
It allows users to store, Create, edit, search, List, and delete contact information.
The system ensures data validation and prevents duplicate phone numbers and email IDs.


2. Features :->

:-> Create Contact
:-> Edit Contact
:-> Delete Contact
:-> Search Contact
:-> List Contact
:-> Save contacts to file
:-> Load contacts from file
:-> Phone number validation (10 digits only)
:-> Email validation (format + duplicate check)
:-> Unique phone and email validation

3. Technologies Used :->

6. Validation Logic :->

= Phone Validation:
= Must be 10 digits
= Only numbers allowed
= No duplicate allowed

Return values:
= 0 → Invalid format
= 1 → Valid
= 2 → Duplicate

Email Validation :->

= Must contain exactly one '@'
= Must contain at least one '.'
= Dot cannot be adjacent to '@'
= No consecutive dots
= No spaces
= No duplicate allowed

Return values:
= 0 → Invalid format
= 1 → Valid
= 2 → Duplicate
